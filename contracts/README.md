# API contracts

`openapi.json` is generated from the FastAPI application and is the source for
browser/client API types. Do not hand-edit it. Regenerate and verify it with:

```sh
PYTHONPATH=python python scripts/openapi.py contracts/openapi.json
PYTHONPATH=python python scripts/check_openapi.py
```

The contract describes the initial session lifecycle boundary and the
authenticated ticket used to open a profile-declared UART terminal. Display,
audio, and remote-device contracts will be added beside it as those
capabilities move.

`openapi-v2.json` is generated by Utoipa from the Rust daemon's API v2
definitions. The daemon also serves it at authenticated
`GET /api/v2/openapi.json`. Regenerate the checked-in copy with:

```sh
cargo run --quiet --bin machineemu-daemon -- --print-openapi > contracts/openapi-v2.json
```

The Rust test suite compares the checked-in copy to the generated document.
The WebSocket route is documented as an HTTP upgrade; its binary protocols and
control messages are described in
[`../docs/operations/api-v2-streams-devices.md`](../docs/operations/api-v2-streams-devices.md).
The live instance SSE stream, event IDs, and reconnect behavior are described
in [`../docs/operations/api-v2-live-vm-events.md`](../docs/operations/api-v2-live-vm-events.md).
The read-only guest-agent information endpoint and its availability response
are described in [`../docs/operations/api-v2-guest-agent.md`](../docs/operations/api-v2-guest-agent.md).
Guest command execution and its dedicated SSE stream are described in
[`../docs/operations/api-v2-guest-exec.md`](../docs/operations/api-v2-guest-exec.md).
Create/start/restart and disposable instance behavior are described in
[`../docs/operations/instance-lifecycle.md`](../docs/operations/instance-lifecycle.md).
